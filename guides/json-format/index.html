JSON整形でエラーを見つける方法

整形は見やすくするだけでなく、APIレスポンスや設定ファイルの構文ミスを早く見つける手段です。

JSON整形とは

JSON整形は、改行とインデントを追加して階層を読みやすくする処理です。minify（圧縮）とは逆の操作で、人が確認する場面に向いています。整形できない場合は、JSONとして正しい構文になっていないことを示します。

よくある4つのエラー

  1. キーがダブルクォートで囲まれていない。 {name: "TxConv"} ではなく {"name": "TxConv"} と書きます。
  2. 文字列にシングルクォートを使っている。 JSONの文字列はダブルクォートのみです。
  3. 最後の要素の後にカンマがある。 {"a": 1,} はJSONでは無効です。
  4. 改行やダブルクォートが文字列内で未エスケープ。 文字列内のダブルクォートは \" と記述します。

確認の順番

まず整形ツールに貼り付け、エラー位置を確認します。次に、括弧 {} と [] の対応、カンマの位置、引用符を順番に見直します。APIから返されたデータなら、HTMLエラーページなどJSON以外の内容が混ざっていないかも確認してください。

機密データの扱い

アクセストークン、メールアドレス、顧客データを含むJSONは、外部サービスに送信しないことが重要です。TxConvのJSON整形はブラウザ内で処理するため、内容をサーバーにアップロードせず確認できます。
